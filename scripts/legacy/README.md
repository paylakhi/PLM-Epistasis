# Historical directional analyses

This directory contains scripts used in earlier exploratory analyses of protein language model (PLM) epistasis scores.

These analyses primarily rank variant pairs according to increasingly negative conditional epistasis scores.

The final manuscript extends these analyses to consider signed and absolute conditional epistasis, matched comparisons between ESM2-650M and VESM-35M, and gene-level cross-validation.

The scripts in this directory are retained for transparency and reproducibility of the earlier analyses. They are not the primary scripts used to generate the final manuscript figures and results.

For the updated analyses, see the main `scripts/` directory.
